# OxidatiOn73 — Журнал лаборатории

SaaS-приложение для малых винодельческих хозяйств. Заменяет Excel-журналы анализа вин. Уникальная фишка — модуль расчёта молекулярного SO₂ и оценки рисков окисления.

> **Текущий статус: прототип на localStorage.**
> Полностью рабочий поток (регистрация, образцы, анализы, графики, PDF) без бэкенда. Данные хранятся в браузере. Supabase подключим, когда дизайн и UX устроят.

## Быстрый старт локально

### Вариант 1: VS Code Live Server (рекомендуется)

1. Открыть папку проекта в VS Code: `File → Open Folder → OxidatiOn73`
2. Установить расширение **Live Server** (Ritwick Dey) — `Ctrl+Shift+X`, искать `Live Server`
3. Кликнуть правой кнопкой по `index.html` → **Open with Live Server**
4. Откроется `http://127.0.0.1:5500/index.html`
5. На странице входа нажать **«Войти в демо-режим →»** — попадёшь в дашборд с примером данных

### Вариант 2: Python (если уже установлен)

```powershell
cd C:\Users\Admin\Desktop\OxidatiOn73
python -m http.server 5500
```

Открыть <http://localhost:5500/>.

### Вариант 3: Просто открыть `index.html` в браузере

Тоже сработает, но Live Server даёт автоперезагрузку при правках.

## Что попробовать в демо

1. **Войти в демо-режим** на стартовой странице.
2. Дашборд: увидишь алерты (риск окисления у Рислинга, высокая VA у Ркацители).
3. Кликнуть алерт → попадёшь в карточку образца с графиком динамики и историей добавок.
4. **«Экспорт PDF»** на карточке — скачает текстовый отчёт.
5. **«Новый анализ»** — попробовать создать новый образец + первый анализ. Поле молекулярного SO₂ считается на лету, при риске показывается доза KMBS.
6. **Модуль SO₂** — три калькулятора и справочник целевых значений.
7. **Настройки → Сбросить локальные данные** — обнулить и попробовать с нуля.

## Структура проекта

```
OxidatiOn73/
├── index.html              — вход / регистрация / демо
├── dashboard.html          — последние анализы + алерты + поиск
├── sample.html             — список + карточка образца (?id=…)
├── new-analysis.html       — форма анализа с авторасчётом мол. SO₂
├── so2-calculator.html     — 3 калькулятора + справочник
├── settings.html           — винодельня, пользователи, сброс
├── css/main.css            — палитра, шрифты, компоненты
├── js/
│   ├── so2-logic.js        — чистые функции SO₂ (используются везде)
│   ├── auth.js             — сессия, регистрация, демо-режим
│   ├── analyses.js         — CRUD образцов/анализов/добавок + сид
│   └── supabase-client.js  — слот под будущее подключение Supabase
└── supabase/               — SQL-миграция и инструкция (будущий шаг)
    ├── setup.sql
    └── README.md
```

## Технологии

- HTML + Tailwind CSS (CDN) + Alpine.js — без сборщиков
- Chart.js — графики динамики
- jsPDF — экспорт карточки образца
- Lucide — иконки
- localStorage — текущее хранилище данных (Supabase — следующий шаг)
